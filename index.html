Stateflow Safety Matrix & EKF Flow

The model computes non-linear cell OCV curves against current draw while executing multi-tier thermal threshold protection (Normal ➔ Derating at 45°C ➔ Emergency Trip at 60°C). 

% Extended Kalman Filter State Estimation
x_hat = A * x_prev + B * I_pack; % State prediction
P = A * P_prev * A' + Q;          % Covariance prediction
K = P * H' * inv(H * P * H' + R); % Kalman Gain
x_hat = x_hat + K * (V_measured - V_ocv(SOC)); % State correction

ADC Sampling & Hysteresis Working Flow

The firmware samples the analog thermistor output at 1kHz using a 12-bit ADC, filters noise with an Exponential Moving Average (EMA), and calculates PID PWM fan speed with 5°C hysteresis to prevent fan motor chatter. 

uint16_t read_engine_temp_adc(void) {
    ADC1->CR2 |= ADC_CR2_SWSTART; /* Start 12-bit conversion */
    while (!(ADC1->SR & ADC_SR_EOC));
    uint16_t raw = ADC1->DR;
    static uint32_t filtered = 0;
    filtered = (filtered * 7 + raw) / 8; /* 8-sample EMA Filter */
    return (uint16_t)filtered;
}

2. Source Code Architecture (timer_isr.c)

/* Hardware Timer Interrupt Handler (10ms Periodic Tick) */
volatile uint32_t remaining_s = 0;
volatile uint8_t  tick_10ms   = 0;

void TIM2_IRQHandler(void) {
    if (TIM2->SR & TIM_SR_UIF) {
        TIM2->SR &= ~TIM_SR_UIF; /* Clear ISR flag */
        tick_10ms = 1;
        static uint8_t sub_counter = 0;
        if (++sub_counter >= 100) { /* 100 x 10ms = 1 sec */
            sub_counter = 0;
            if (remaining_s > 0) remaining_s--;
        }
    }
}

/* 12-Bit ADC Sampling with Moving Average Filter */
uint16_t read_engine_temp_adc(void) {
    ADC1->CR2 |= ADC_CR2_SWSTART; /* Trigger ADC conversion */
    while (!(ADC1->SR & ADC_SR_EOC)); /* Wait conversion */
    uint16_t raw_adc = ADC1->DR;
    
    /* 8-sample Exponential Moving Average */
    static uint32_t filtered = 0;
    filtered = (filtered * 7 + raw_adc) / 8;
    return (uint16_t)filtered;
}
